# Jama ustna

Fotorealistyczna mowa wymaga wnętrza jamy ustnej. Sama powierzchnia warg jest niewystarczająca przy szerokim otwarciu ust i wielu fonemach.

## Elementy

- górne zęby związane z głową;
- dolne zęby związane z żuchwą;
- język z własną geometrią i uproszczonym sterowaniem;
- dziąsła i ciemna geometria wnętrza ust;
- brak szczelin widocznych przy skrajnych pozach.

Język nie musi mieć pełnej biomechaniki, ale powinien umożliwiać podstawowe pozy dla artykulacji i nie przenikać przez zęby.
