# 06. UV

**Input:** zamrożona topologia.  
**Editable output:** UV zapisane w kanonicznej scenie.  
**Derived output:** checker report i texel-density report.

## Windows

1. Zdefiniuj osobne zestawy materiałowe: head/skin, body, eyes, mouth, hair, clothing, glasses.
2. Rozmieść seams poza regionami pierwszoplanowymi twarzy.
3. Ustal spójną texel density.
4. Sprawdź checker bez deformacji i na testowych pozach.
5. Zapisz layout przed rozpoczęciem teksturowania.

## Linux

1. Utwórz UV dla zatwierdzonej topologii.
2. Priorytetyzuj twarz, dłonie i regiony wymagające detalu.
3. Zachowaj marginesy wysp adekwatne do mipmappingu.
4. Zweryfikuj overlap tylko tam, gdzie jest świadomie zaprojektowany.
5. Zapisz raport layoutu.

## DoD

Brak niezamierzonego overlapu, rozciągnięcia w krytycznych regionach i zbyt małych marginesów; texel density jest jawnie zdefiniowana.
