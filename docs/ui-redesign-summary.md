# Przebudowa interfejsu strony

Strona została przebudowana tak, aby najpierw prezentowała projekt, model 3D i proces jego tworzenia. Materiał teoretyczny jest dostępny później, w grupie „Wiedza”.

Najważniejsze zmiany:
- ekran startowy skupia się na celu projektu i finalnym awatarze,
- model 3D jest głównym elementem wizualnym,
- pipeline jest pokazany jako sześć czytelnych etapów,
- PBR, UV, blendshapes i kontrola jakości są zgrupowane w sekcji wiedzy technicznej,
- opisy teoretyczne zawierają praktyczne przykłady odnoszące się bezpośrednio do twarzy i modelu 3D,
- nawigacja została uproszczona.
