# Speech animation

Wiarygodna wypowiedź łączy lip-sync z zachowaniem całej postaci.

## Warstwy podczas mowy

- visemy i żuchwa;
- ekspresja emocjonalna;
- mruganie;
- gaze shifts;
- drobne ruchy głowy;
- gesty zsynchronizowane z frazami;
- idle o zredukowanej amplitudzie.

Nie należy sterować gestami amplitudą audio. Semantyczne akcenty powinny wynikać z tekstu, prozodii lub ręcznego authoringu.
