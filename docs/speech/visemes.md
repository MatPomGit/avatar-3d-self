# Visemy

Visem grupuje fonemy o podobnym wyglądzie artykulacji. Mapowanie fonem → visem powinno być zależne od języka i testowane na konkretnym facial rigu.

## Zasady

- jawOpen jest sterowany częściowo niezależnie od kształtu warg;
- bilabialne wymagają pełnego zwarcia warg;
- samogłoski wykorzystują ciągłe przejścia między kształtami;
- język i zęby wpływają na wiarygodność części fonemów;
- wartości visemów nie są binarne.

Mapowanie przechowuj jako jawny plik konfiguracyjny, aby można było je stroić bez przebudowy rigu.
