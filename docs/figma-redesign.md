# Makieta redesignu strony projektu

Makieta interfejsu została przygotowana w Figma jako punkt odniesienia dla przebudowy strony GitHub Pages.

Figma: https://www.figma.com/design/ahNo1EmkyVS7567Q9noBAd

Założenia:
- ekran startowy prezentuje przede wszystkim projekt i rezultat 3D,
- główna nawigacja prowadzi do projektu, pipeline, modelu 3D, narzędzi i uruchomienia,
- PBR, UV, blendshapes i kontrola jakości są zgrupowane jako wiedza techniczna,
- teoria jest pokazywana na prostych przykładach praktycznych.
