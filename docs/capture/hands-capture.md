# Capture dłoni

Dłonie fotografuj osobno w wysokiej rozdzielczości.

Wykonaj stronę grzbietową, dłoniową, oba boki, opuszki, paznokcie oraz przestrzenie między palcami. Zarejestruj dłoń otwartą i kilka funkcjonalnych konfiguracji jako materiał referencyjny dla deformacji.

Dla fotogrametrii unikaj ruchu palców pomiędzy zdjęciami. Jeśli pełna rekonstrukcja dłoni jest niestabilna, traktuj zdjęcia jako źródło proporcji i detali dla modelowania ręcznego.
