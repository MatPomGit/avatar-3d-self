# Web

Publiczna strona projektu nie jest runtime viewerem ani panelem postępu. GitHub Pages publikuje wyłącznie MkDocs.

Jeżeli w przyszłości powstanie publiczny demonstrator WebGL/WebGPU, będzie osobnym artefaktem i użyje zoptymalizowanego GLB z publicznie zatwierdzonymi teksturami. Nie będzie miał dostępu do prywatnego workspace Avatar Studio.

## Windows

Dokumentację lokalnie uruchamiaj przez `mkdocs serve`; nie jest wymagany Node.js.

## Linux

Dokumentację lokalnie uruchamiaj identycznie przez `mkdocs serve`.
