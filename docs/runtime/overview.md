# Runtime

Runtime jest docelowym środowiskiem, w którym avatar musi zachować wygląd, rig, facial controls, mowę i wydajność.

## Pakiet importowy

Powinien zawierać model, materiały, tekstury, skeleton, blend shapes, animacje, konfigurację visemów oraz raport konwersji. Każdy eksport jest artefaktem pochodnym względem źródłowej sceny DCC.

Zobacz: [performance budget](performance-budget.md), [LOD](lod.md), [Unreal](unreal.md), [Unity](unity.md) i [Web](web.md).
