# Unity

Unity jest wspieranym kierunkiem interoperacyjności, ale nie jest automatycznie równoważny z Unreal.

## Windows

1. Wybierz konkretną wersję Unity i URP albo HDRP.
2. Zaimportuj FBX/GLB i sprawdź Avatar/skeleton mapping.
3. Zweryfikuj blend shapes i ich nazwy.
4. Odtwórz materiały PBR dla wybranego render pipeline.
5. Uruchom te same acceptance clips i profiler.

## Linux

1. Użyj tej samej wersji Unity i render pipeline.
2. Zaimportuj identyczny pakiet.
3. Porównaj wyniki skeleton/blend shapes.
4. Zweryfikuj shadery skóry, oczu i włosów na backendzie Linux.
5. Zapisz oddzielny raport.
