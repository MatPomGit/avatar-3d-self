# Materiały oczu

Realistyczne oko jest układem kilku warstw optycznych, nie pojedynczą teksturą na kuli.

Minimalnie rozdziel: twardówkę, tęczówkę, źrenicę i rogówkę. Rogówka powinna zapewniać poprawne refleksy i refrakcję zgodną z możliwościami renderera. Twardówka nie powinna być czysto biała, a roughness i drobne unaczynienie muszą pozostać subtelne.

Materiał należy oceniać razem z geometrią powiek, meniskiem łzowym i kierunkiem spojrzenia.
