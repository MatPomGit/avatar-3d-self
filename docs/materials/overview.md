# Materials

Materiały Avatar Studio stosują workflow PBR. Każdy zasób powinien mieć jawnie określony model materiałowy, przestrzeń barwną map i docelową rozdzielczość.

Przeczytaj kolejno: [PBR conventions](pbr-conventions.md), [skin](skin.md), [eyes](eyes.md), [hair](hair.md) i [clothing](clothing.md).

Materiały są zależne od UV i nie powinny utrwalać błędów geometrii. Normal, displacement i albedo mają odwzorowywać różne klasy informacji.
