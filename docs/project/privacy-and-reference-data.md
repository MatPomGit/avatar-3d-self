# Prywatność i dane referencyjne

Fotografie twarzy i ciała, skany 3D, nagrania głosu oraz adnotacje ekspresji są danymi silnie identyfikującymi osobę. Publiczne repozytorium nie jest ich magazynem.

## Zasady

- raw capture pozostaje w prywatnym workspace;
- usuń GPS/EXIF z kopii przeznaczonych do publikacji;
- publiczny manifest nie zawiera dokładnej lokalizacji ani danych kontaktowych;
- treningowe nagrania Piper nie są publikowane automatycznie;
- raport może zawierać hashe i parametry techniczne bez surowej treści;
- backup prywatnego workspace musi mieć kontrolę dostępu i szyfrowanie adekwatne do ryzyka.

## Publiczne repozytorium

Dopuszczalne są schematy manifestów, przykładowe dane syntetyczne, kod, metryki zagregowane i jawnie zatwierdzone materiały demonstracyjne. Avatar Studio powinno domyślnie tworzyć workspace poza katalogiem repozytorium.
