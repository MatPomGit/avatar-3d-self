# Gesty

Gesty powinny wspierać treść wypowiedzi, a nie działać jako losowa dekoracja.

## Kategorie

- deiktyczne: wskazywanie osoby, obiektu lub kierunku;
- ikoniczne: odwzorowanie kształtu lub ruchu;
- rytmiczne: podkreślenie akcentu wypowiedzi;
- adaptacyjne: drobne ruchy spoczynkowe.

## Zasady

Gest zaczyna się zwykle przed słowem, które podkreśla. Unikaj idealnego powtarzania tych samych klipów i symetrycznych ruchów obu rąk. Dłonie powinny mieć sensowną konfigurację palców, a nie pozostawać stale otwarte.
