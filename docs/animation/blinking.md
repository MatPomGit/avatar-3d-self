# Mruganie

Mruganie nie powinno być zegarem o stałym okresie.

## Model

Częstotliwość zależy od kontekstu, ruchu oczu i wypowiedzi. Mrugnięcie może wystąpić przy zmianie kierunku spojrzenia, granicy frazy lub po dłuższej fiksacji.

Górna powieka wykonuje większość ruchu. Dolna powieka może reagować subtelnie. Lewa i prawa strona nie muszą być matematycznie identyczne, ale duże różnice wymagają uzasadnienia.

## Walidacja

Sprawdź pełne zwarcie powiek, brak penetracji rogówki i płynny powrót do pozycji otwartej.
