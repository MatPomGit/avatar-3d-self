# Gaze

Spojrzenie jest jednym z najsilniejszych sygnałów życia postaci.

## Architektura

Target spojrzenia steruje oddzielnie oczami i głową. Oczy rozpoczynają sakkadę wcześniej, głowa dołącza z mniejszą amplitudą. Powieki powinny reagować na pionowy kierunek spojrzenia.

## Zachowanie

- krótkie fiksacje zamiast ciągłego płynnego śledzenia;
- mikrosakkady przy dłuższych fiksacjach;
- okazjonalne odwrócenie wzroku podczas mowy;
- poprawna konwergencja dla bliskich obiektów.

Błąd konwergencji lub martwe, stale wycentrowane oczy silnie zwiększają uncanny valley.
