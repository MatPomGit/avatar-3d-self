# ADR-0004: Nazewnictwo i styl Pythona

**Status:** zaakceptowana, 2026-09-01

## Kontekst

Różne konwencje nazw powodowały ryzyko błędów na systemach rozróżniających wielkość liter. Kod Python wymagał lekkiego, jasnego standardu jakości.

## Decyzja

Szczegółowe zasady nazw, PEP 8, PEP 257 i KISS są utrzymywane wyłącznie w [architekturze](../architecture.md).

## Konsekwencje

Nowe i modyfikowane pliki są zgodne ze standardem. Nazwy istniejące zmienia się wyłącznie razem z referencjami i tylko wtedy, gdy przynosi to wymierną korzyść.
