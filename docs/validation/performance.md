# Walidacja wydajności

Wydajność mierzy się w target runtime, nie na podstawie samej liczby polygonów.

Raportuj FPS/frame time, draw calls, triangles, vertices, liczbę materiałów, pamięć tekstur, koszt groom, liczbę aktywnych blend shapes, kości oraz koszt animacji.

Profile wykonuj w scenie reprezentatywnej dla zastosowania. Budżet z [performance budget](../runtime/performance-budget.md) traktuj jako kontrakt projektu, a nie wartość orientacyjną bez pomiaru.
