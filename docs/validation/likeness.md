# Walidacja podobieństwa

Podobieństwo ocenia się przed stylizacją, oświetleniem filmowym i postprocessingiem.

## Procedura

Porównaj model z referencjami frontalnie, z profilu i 3/4 przy podobnej ogniskowej. Używaj nakładek landmarków i sylwetki. Oddziel ocenę geometrii od materiałów.

## Priorytety

Oczy i oczodoły, nos, usta, żuchwa, proporcje czaszki, uszy, linia włosów, zarost, okulary oraz proporcje całej sylwetki.

Nie zatwierdzaj modelu tylko dlatego, że pojedynczy render wygląda podobnie. Likeness musi być stabilne w wielu kątach.
