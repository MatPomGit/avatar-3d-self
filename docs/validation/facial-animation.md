# Walidacja facial animation

Oceniaj pojedyncze kontrolery, kombinacje oraz animację ciągłą.

## Testy

- pełne mrugnięcie bez penetracji oka;
- niezależne spojrzenie i eyelid follow;
- jawOpen z dolnymi zębami i językiem;
- smile/frown lewo i prawo;
- brow motion;
- skrajne samogłoski i bilabial closure;
- mieszane emocje podczas mowy.

Kontroluj asymetrię, timing i brak nagłych skoków. Poprawna lista blend shapes nie wystarcza, jeśli animacja wygląda mechanicznie.
