# Walidacja deformacji

Deformacja jest poprawna, gdy zachowuje objętość i charakter anatomiczny w pełnym zakresie ruchu.

Testuj barki, łokcie, nadgarstki, palce, kręgosłup, biodra, kolana, stopy, szyję i żuchwę. Dla twarzy użyj jednostkowych i kombinowanych ekspresji.

Błędy krytyczne: collapse objętości, candy-wrapper twist, clipping, rozciągnięcie UV, nienaturalna zmiana sylwetki i niestabilne okulary/ubrania.
